# EPIC-084: Динамический батчинг без ограничения размера пакета

- **Статус:** done
- **Создан:** 2026-10-11
- **Завершён:** 2026-10-11
- **Roadmap:** [блок Л](../roadmaps/llm_serving_catchup_roadmap.md), пункт Л1

## Цель

Довести модель Inoue (2021) до воспроизводимого расчёта средних ожидания и
пребывания, проверить точность опубликованных границ и обеспечить независимые
эталоны. Не объявлять численное усечение точным решением бесконечной цепи.

## Контекст и атрибуция

Y. Inoue, Performance Evaluation 147 (2021), 102183,
[doi:10.1016/j.peva.2020.102183](https://doi.org/10.1016/j.peva.2020.102183),
[arXiv:1912.06322v3](https://arxiv.org/html/1912.06322v3), прочитан целиком.
Модель, вложенная цепь, Леммы 2–5 и Теорема 2 принадлежат автору.
Усечение обсуждается уже в §3.1; точность границ и роль простоя — в §4.
Инженерная реализация, не заявка на новизну.

Прицельная проверка предшествующих работ, вывод формул, численные результаты,
найденные дефекты и независимые арбитры:
[методический отчёт](../research/dynamic-batching-validation-2026.md).

## Задачи

- [x] `DynamicBatchingCalc(BaseQueue)`, совместимые `set_sources/set_servers/run`,
  результаты `DynamicBatchingResults(QueueResults)`, первый момент w/v.
- [x] Детерминированное, exponential, Erlang, gamma с нецелым shape, H2:
  аффинное среднее, прямые пуассоновские смеси, без фазовой подмены gamma.
- [x] Проверки конечности параметров, целочисленных размеров, нагрузки и существования
  конечного среднего ожидания; пределы памяти/состояний.
- [x] Адаптивное усечение с уточнением, моментными и стационарными диагностиками;
  отказ при недостигнутой точности; фиксированное N явно несертифицировано.
- [x] Границы Теоремы 2, отчёт о простое и зазоре; сетка 60 режимов
  в `examples/dynamic_batching_experiment.py` и сохранённом JSON.
- [x] Независимый DES для пяти законов; согласованное исключение прогрева,
  полные измеряемые пакеты, моменты w/v, занятость и временная PMF.
- [x] Замкнутые α=0 и τ₀=0 эталоны, квадратура, предельный переход от
  существующего CTMC с физическим потолком пакета, репликации DES.
- [x] Исправлены завышенные утверждения черновика о точности, новизне и знаке
  переходного смещения; отделены waiting и latency.
- [x] EN/RU страницы модели и схема, README, каталоги, simulation guide.
- [x] Полная регрессия и финальный контроль форматирования/линтера.
- [x] Roadmap, реестр эпиков, карточка источника и заметка в память синхронизированы.

Общий callback-интерфейс для законов H[b] вне пяти перечисленных семейств переносится
в Л2 вместе с неаффинной зависимостью от максимальной длины вывода. Здесь реализован
полный набор **именованных законов Л1**; произвольный пользовательский sampler/PMF
не заявляется. Аналитические CDF и старшие моменты задержки не входили в Л1.

## Критерии готовности

Общий [DoD](../DOD.md), плюс: нельзя обойти проверку конечности среднего через
усечение; нельзя выдавать массу границы за гарантированную ошибку; симуляция не
использует переходную матрицу калькулятора; физический cap не смешивается с N.
Следующий пункт Л2 не начинается в рамках этого эпика.

## Результаты

Целевые проверки: **115 passed**, включая slow-проверку тяжёлой нагрузки.
Быстрый набор репозитория: **2730 passed**, полный: **2740 passed**, 16 предупреждений
в существующих тестах (304 с и 465 с, 20 workers, BLAS/OMP по одному потоку).
Команды соответствуют CI с `--reruns 1 --only-rerun AssertionError`; повторов
в итогах этих прогонов не было. После последнего защитного условия на размер
выделения дополнительно пройдены три теста бюджетов и ручные extreme-input проверки.
Black/isort — чисто; pylint двух новых модулей и скрипта — **10/10**;
общий pylint — **9.98/10**, без замечаний в новых модулях.
Проверено 148 локальных ссылок в README и новых страницах.
Повторная генерация экспериментального JSON побайтово совпала.

На сетке 60 режимов максимальное завышение лучшей границы — **7.3792%**;
при τ₀/α=8 и ρ=0.3 — **0.4042%**, а не численная точность.
Сверка с независимым capped-CTMC при cap=32 даёт разность среднего ожидания
менее **2·10⁻¹⁰** для λ=1, α=0.1, τ₀=0.5.

Основные ограничения: один сервер, Poisson, неограниченный физический пакет,
нет KV-cache и токенового continuous batching, только средние задержки.
Диагностики сходимости не являются доказанной оценкой погрешности.
Данные сетки синтетические, не результаты запуска GPU.
