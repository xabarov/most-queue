# EPIC-029: EDF (Earliest Deadline First) scheduling discipline

- **Статус:** done
- **Создан:** 2026-09-29
- **Roadmap:** [../roadmaps/edf_scheduling_roadmap.md](../roadmaps/edf_scheduling_roadmap.md)

## Цель

Добавить EDF как **дисциплину обслуживания** (не только post-hoc SLA-расчёт поверх FCFS, как
EPIC-021): заявка с ближайшим дедлайном обслуживается первой. DES-симулятор + точный инвариант
(закон сохранения работы) + композиция с уже готовым SLA-слоем (EPIC-021) для вероятности
нарушения дедлайна на класс.

## Контекст

Обзор литературы: [../research/edf-scheduling-2026.md](../research/edf-scheduling-2026.md).
Точный конечномерный (CTMC/closed-form) анализ EDF в общем случае — открытая исследовательская
задача (подтверждено литературой: только heavy-traffic/fluid-результаты существуют) и лично
проверено двумя отвергнутыми гипотезами (SIRO-эквивалентность при экспоненциальных дедлайнах;
агрегированная CTMC через "гонку" экспоненциальных часов по классам — обе численно опровергнуты;
статическая приоритетность по классу дедлайна — опровергнута аналитически через классический
результат Liu-Layland/Leung-Whitehead о строгом превосходстве EDF над fixed-priority). Поэтому
эпик даёт DES (точна "по построению") + один строго точный инвариант (закон сохранения работы,
верен для любой non-idling дисциплины) вместо ложно-точной теории.

## Задачи

### Ядро

- [x] `most_queue/sim/edf.py` (новый файл): `EDFQueueSim` — `K` классов, общий сервер, дедлайн на
      класс любого распределения (через `create_distribution`, Кендалл-нотация), заявка
      покидает систему, если дедлайн наступил раньше начала обслуживания.
- [x] `EDFResults` (`most_queue/structs.py`) — per-class `w`, `v`, `miss_prob`, `utilization`.

### Инвариант и тесты

- [x] Закон сохранения работы (`Σ ρ_k W_k = ρ·E0/(1-ρ)`) как regression-тест на выходе DES — **только
      в конфигурации с пренебрежимо редким reneging** (при заметном reneging закон не выполняется
      точно, см. research-доку п.3 "Rejected hypotheses" — численно проверено и задокументировано).
- [x] EDF снижает суммарную `miss_prob` относительно FCFS (реализовано через параметр
      `discipline="fcfs"` на том же `EDFQueueSim` — честнее прямого сравнения с
      `PriorityQueueSimulator`, поскольку сохраняет идентичную механику reneging).
- [x] Монотонность: более короткий дедлайн класса => меньше его `miss_prob`.
- [x] `v = w + E[S]`.

### Композиция с EPIC-021

      должна быть малой (обслуженная заявка по построению не превысила дедлайн).

## Критерии готовности (DoD эпика)

Общий DoD — [../DOD.md](../DOD.md). Специфично:

1. Закон сохранения работы выполняется на выходе DES в пределах статистической погрешности.
2. EDF даёт не худший (обычно лучший) суммарный `miss_prob`, чем FCFS, на тех же параметрах.
3. Документация (EN+RU) честно описывает объём точности (DES + один точный инвариант, не полная
   точная теория per-class распределения).

## Результаты

Реализовано по плану ([roadmap](../roadmaps/edf_scheduling_roadmap.md)). Кратко:

- **Ядро:** `EDFQueueSim` (`most_queue/sim/edf.py`) — `K` классов, общий сервер, дедлайн на класс
  любого распределения (Кендалл-нотация), заявка покидает систему при истечении дедлайна до
  начала обслуживания (reneging). Параметр `discipline="edf"|"fcfs"` — честная FCFS-с-reneging
  база для сравнения (та же механика прихода/обслуживания/reneging).
- **Точной теории намеренно нет**: перед тем как остановиться на DES-only объёме, проверены и
  отвергнуты четыре гипотезы о «неожиданном точном сведении» (детали и численные доказательства —
  в research-доке): (1) экспоненциальные дедлайны ≠ SIRO; (2) агрегированная `(n1,n2)`-CTMC через
  «гонку» экспоненциальных часов по классам ≠ истинный EDF (систематическое расхождение ~10-15% по
  3 сидам); (3) статическая приоритетность по классу дедлайна ≠ EDF (аналитически, через
  классический результат Liu-Layland/Leung-Whitehead о превосходстве EDF над fixed-priority);
  (4) классический закон сохранения работы не точен при заметном reneging (соотношение LHS/RHS
  ≈0.35 при ~20% miss rate), но асимптотически верен при reneging→0 (0.90 при 1%, 0.97 при 0.1%) —
  подтверждает корректность самого симулятора.
- **Тесты:** `tests/units/test_edf.py` — 9 passed (закон сохранения в режиме редкого reneging,
  EDF<FCFS по средней `miss_prob`, монотонность по щедрости дедлайна, `v=w+E[S]`, детерминированный
  дедлайн, композиция с `sla.deadline_violation_prob`, валидация некорректных параметров). Полный
  прогон `tests/` — **586 passed, 0 failed** (994s), регрессий нет.
- **Документация:** новая модель `docs/models/edf.md`/`.ru.md` (честно про объём точности), новые
  строки в `docs/models.md`/`.ru.md`.
- **Резерв на будущее:** точный closed-form/series калькулятор среднего ожидания для 2-классового
  delayed-APQ (Mojalal, Stanford, Taylor & Ziedins) — требует восстановления формул из paywalled
  источников; многоканальный и preemptive EDF.
