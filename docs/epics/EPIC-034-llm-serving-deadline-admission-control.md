# EPIC-034: M/M/1 с точным admission control по дедлайну (LLM-serving SLO)

- **Статус:** done
- **Создан:** 2026-09-29
- **Roadmap:** [../roadmaps/llm_serving_deadline_admission_control_roadmap.md](../roadmaps/llm_serving_deadline_admission_control_roadmap.md)

## Цель

Добавить **admission control** по дедлайну — третий, качественно новый механизм SLO-управления
очередью, отличный и от EDF (EPIC-029, порядок обслуживания) и от SLA-слоя (EPIC-021, пассивный
пост-расчёт): при приходе клиент с дедлайном `D~Exp(θ)` либо принимается (FCFS-порядок сохраняется)
либо немедленно отклоняется, если его дедлайн уже неосуществим при текущей загрузке.

## Контекст

Обзор литературы: [../research/llm-serving-deadline-admission-control-2026.md](../research/llm-serving-deadline-admission-control-2026.md).
Прямой прецедент — Das, Jenkins & Sengupta, *Analysis of an M/M/1+G queue operated under the FCFS
policy with exact admission control*, Queueing Systems, 2013 (paywalled — вывод независимый).
Первая гипотеза (цепь рождения-гибели по `n` с `P(admit|n)=(μ/(μ+θ))^n`) оказалась НЕВЕРНОЙ —
поймано численно (несоответствие эмпирической `P(admit|n)` в DES) и объяснено аналитически
(`n` не достаточная статистика из-за смещения по `tail_D`, не стираемого memorylessness). Верный
вывод — через level-crossing уравнение для НЕПРЕРЫВНОГО workload-процесса (Takács), даёт
рекурсивное функциональное уравнение `phi(s)=pi0+[λ/(s+μ)]phi(s+θ)`, решаемое быстро сходящимся
рядом. Полностью проверено против независимой DES (несколько сидов, несколько моментов).

## Результаты

Реализовано по плану ([roadmap](../roadmaps/llm_serving_deadline_admission_control_roadmap.md)),
после существенного исследовательского отклонения. Кратко:

- **Ядро:** `MM1DeadlineAdmissionControlCalc` — точное (сходящийся ряд) решение level-crossing
  функционального уравнения `phi(s)=pi0+[λ/(s+μ)]phi(s+θ)` для ПЭП загрузки `U`; моменты извлекаются
  через ТОЧНУЮ арифметику усечённых степенных рядов (не конечные разности) — `pi0`, `loss_prob`,
  `get_u_moments`, `get_u_moments_admitted`; моменты `V` принятых — через `conv_moments`.
- **Путь к результату:** первая (заманчиво простая) гипотеза — цепь рождения-гибели по `n` с
  `P(admit|n)=(μ/(μ+θ))ⁿ` — оказалась НЕВЕРНОЙ: `n` не достаточная статистика, т.к. обусловливание
  на факте приёма смещает загрузку через хвост дедлайна, и это смещение НЕ стирается
  memorylessness обслуживания (только «время с последнего перехода» стирается ей, а не
  обусловливание на прошлом сравнении). Поймано численно (устойчивое по сидам расхождение
  эмпирической `P(admit|n)` от формулы) ДО написания финального кода. Верный вывод — через
  level-crossing для непрерывного workload-процесса (Takács), что и предполагала оригинальная
  статья 2013 года (недоступная полностью).
- **Найденные и исправленные ошибки:** (1) в первой версии самого функционального уравнения —
  ошибка размерности (`(1-phi(s))/s` вместо `phi(s)-pi0`), поймана анализом размерностей ДО
  повторной численной проверки; (2) численное переполнение `float64` при больших `θ`/`num_terms`
  (накопление `C_n` целиком перед взятием обратного) — исправлено накоплением обратного
  ПОЭЛЕМЕНТНО; (3) две неверные интуиции в тестах (`loss_prob→1` при `θ→∞` — неверно, `pi0`
  положительный атом; направление монотонности `E[W|admitted]` по `θ` — тоже было перепутано) —
  обе исправлены проверкой против DES/прямого вычисления, а не интуиции.
- **Проверка:** полностью подтверждено независимой (написанной с нуля, НЕ `n`-based) непрерывной
  workload-DES — `pi0`, `E[U]`, `loss_prob`, `E[V|admitted]`, `E[V²|admitted]` совпадают в пределах
  MC-погрешности на нескольких сидах и параметрах.
- **Тесты:** `tests/units/test_mm1_deadline_admission_control.py` — 8 passed;
  `tests/test_admission_control.py` — 2 passed (DES кросс-валидация). Полный прогон `tests/` —
  **654 passed, 0 failed** (887s), регрессий нет.
- **Документация:** новая модель `docs/models/admission-control.md`/`.ru.md` (EN+RU, честно про
  отвергнутую гипотезу и резерв), перекрёстные ссылки в `docs/models/sla.md`/`.ru.md`, новые
  строки в `docs/models.md`/`.ru.md`.
- **Резерв на будущее:** общий (не экспоненциальный) дедлайн `G` — трюк со сдвигом `phi(s+θ)`
  специфичен для константного отношения хвоста экспоненты; общий `G` требует дискретизации
  интегрального уравнения Вольтерра напрямую. Многоканальный (`c>1`) admission control.
