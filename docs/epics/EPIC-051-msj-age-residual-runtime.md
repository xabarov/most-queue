# EPIC-051 — MSJ прогноз остатка по возрасту и цензурированная история

## Цель

Прогнозировать остаток S−a выполняющейся работы, когда известно S>a, а не
вычитать возраст из фиксированной оценки. Корректно использовать историю,
в которой часть работ ещё не завершилась. Проверить последствия обновлений
для задержек и ранее обещанных стартов EASY/conservative.

## Задачи

- [x] Kaplan–Meier survival estimator по наблюдаемому min(S,C) и индикатору
      завершения; условный остаточный квантиль и среднее/ограниченное среднее.
- [x] Явная недоступность хвостового прогноза при недостаточной наблюдаемости,
      без допущения, что цензурированные работы завершились в C.
- [x] Opt-in обновление прогнозов активных работ в MSJ только по классу и
      возрасту, без передачи будущего сервиса/завершения; старый API сохранён.
- [x] При увеличении прогнозного освобождения инвалидировать conservative
      календарь, не стирать исторические обещания; при отсутствии оценки
      приостановить новый backfill, сохранить FCFS и дренирование всех работ.
- [x] Точные тесты KM, ties, независимости от скрытого S, предельных случаев;
      сверка с SciPy и M/E2/1 по общим допускам; тесты календаря/ресурсов.
- [x] Воспроизводимый парный эксперимент: fixed/age KM, fixed/age completed-only,
      oracle, FCFS/EASY/conservative, контроль нагрузки, отдельные метрики обещаний
      и условного остатка; отчёт и EN/RU документация.
- [x] Быстрый и полный pytest, black/isort, pylint без новых замечаний;
      закрытие эпика и обновление roadmap.

## Математический и информационный контракт

Независимое правое цензурирование внутри ресурсного класса. Kaplan–Meier
`S_hat(t)=product_{u<=t}(1-d_u/n_u)`: завершения в момент u учитываются при риске,
включающем цензурированные в этот же момент. Условный survival остатка
`S_hat(a+r)/S_hat(a)`, если знаменатель положителен. Квантиль ищется без
экстраполяции хвоста; если порог не достигнут или S_hat(a)=0, вернуть None.
Полное среднее недоступно при положительном ненаблюдаемом хвосте; ограниченное
среднее допускается только до заданного наблюдаемого горизонта.

Это plug-in оценки, не новые conformal-границы и не 90%/95% гарантия для очереди.
API не может проверить независимость цензурирования или происхождение данных.
Историческая модель фиксируется до replay. Обновления используют только текущий
класс и возраст и выполняются на уже существующих событиях arrivals/completions/
reservations; отдельный периодический таймер и online-переобучение вне эпика.
Waiting jobs сохраняют начальные оценки. Политика пересборки календаря при
расширении прогнозов явная; прежние обещания остаются в счётчике нарушений.

## Протокол до запуска

Два закона сервиса предыдущего генератора (Erlang-2/lognormal остаточный шум с
признаком размера), три класса K=1,3,4. В этом baseline survival оценивается
по классу, без дополнительного conditioning на размер входа. История 4000 работ,
независимый C~Exp(mean=5*E[S|class]); наблюдаются min(S,C) и completed=(S<=C).
Completed-only baseline исключает цензурированные работы и намеренно показывает
ошибку такого подхода. История и test генерируются независимо до планирования.

Квантиль 0.90 фиксируется заранее. Два уровня ресурсной нагрузки 0.35/0.55,
400 warm-up и 4000 измеряемых приходов, восемь новых seed 51000–51007.
FCFS плюс EASY/conservative × (km_fixed, km_age, completed_fixed, completed_age,
oracle): 352 scheduler-прогона. Внутри сравнения одинаковая фактическая работа;
age и fixed одного estimator получают одинаковые стартовые оценки.
Дополнительная оценка остатка на заранее заданных возрастах 0, E[S|class],
3*E[S|class]; недоступные квантили явно помечаются, заявки из replay не удаляются.
Интервалы по независимым seed, сравнения парные; без поправки на множественность.

## Источники и границы

- Kaplan, Meier. *Nonparametric Estimation from Incomplete Observations*, JASA,
  1958, [DOI 10.1080/01621459.1958.10501452](https://doi.org/10.1080/01621459.1958.10501452).
- Tsafrir, Etsion, Feitelson. *Backfilling Using System-Generated Predictions
  Rather Than User Runtime Estimates*, TPDS, 2007,
  [DOI 10.1109/TPDS.2007.70606](https://doi.org/10.1109/TPDS.2007.70606).
  Мотивация динамической коррекции; эвристики статьи не выдаются за наш алгоритм.
- [SciPy 1.13 ecdf](https://docs.scipy.org/doc/scipy-1.13.0/reference/generated/scipy.stats.ecdf.html)
  — независимая программная сверка KM для правого цензурирования.

Не заявляются: новая survival-теория, guaranteed conditional coverage,
стационарный SLO, адаптация к drift, поддержка информативного цензурирования,
реальные кластерные трассы или новые дисциплины MSFQ/ServerFilling.

## Результаты реализации и эксперимента

- `KaplanMeierRuntimeEstimator`, условные квантили и полное/ограниченное среднее,
  неизменяемые risk-set диагностики и явные неподдержанные хвосты.
- `remaining_predictor(cls, age)` в `MsjGeneralSim.run/run_trace`; пересборка
  conservative календаря без стирания прежних обещаний, FCFS при недоступности.
  Положительный остаток меньше точности timestamp также трактуется как
  недоступный release; это предотвращает цикл на дискретном survival-атоме.
- 352 scheduler-прогона, 288 landmarks, 16 независимых историй, строгие JSON.
  Аудированы отпечатки и парные интервалы; 88 полных replay воспроизведены точно.
- Восемь из восьми парных интервалов среднего T для KM-age−KM-fixed ниже нуля;
  общего выигрыша p99 не установлено. У EASY/lognormal широкие классы медленнее;
  K=4 на 3mu имеет конечный KM-квантиль только в 3/8 повторов.
- 77 новых тестовых случаев, включая SciPy KM и две сверки M/E2/1.
- Итоговый быстрый pytest: **1039 passed**; полный: **1048 passed**,
  оба с 16 прежними предупреждениями. Black/isort и `git diff --check` пройдены;
  pylint по новым/изменённым модулям MSJ, примеру и тестам — 10/10, по всему
  `most_queue` те же 43 замечания, без новых. Исполняемый пример и ссылки проверены.
- [Методика и пример EN](../msj_age_runtime.md), EN/RU страницы модели и симуляции;
  [полный отчёт](../research/msj-age-runtime-results-2026-10.md),
  [артефакты и команды](../../works/msj_age_runtime/README.md).

Не расширено на drift, survival-регрессию или реальные трассы. Следующий кандидат
roadmap — информационно сопоставимые MSFQ/ServerFilling baseline с отдельной
проверкой широких классов и обещаний; это не входит в EPIC-051.

При проверке один предварительный быстрый запуск поймал падение старого
несидерованного `test_mgn_h2_delay_cold_warm` на старших моментах; отдельный
повтор и итоговые быстрый/полный прогоны прошли без изменения кода или допусков.

после чего весь набор был успешно выполнен заново.
