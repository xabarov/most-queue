# EPIC-050 — MSJ калибровка прогнозов по ресурсным классам

- **Статус:** done
- **Создан:** 2026-10-02
- **Завершён:** 2026-10-02

## Цель

Проверить цену защиты широких заявок: EPIC-049 дал около 95% общего покрытия,
но лишь 87.81% для K=4 в iid/lognormal. Добавить отдельные conformal-пороги
по заранее известным ресурсным классам и сравнить их с общей калибровкой.
Результат не должен подменять покрытие прогнозов гарантией расписания или SLO.

## Задачи

- [x] Расширить predictor API групповой калибровкой без изменения существующих
      pooled/point вызовов; группы доступны при поступлении, модель общая.
- [x] Явные диагностики малого n, отказ от конечного прогноза для редких/неизвестных
      групп, без скрытого pooled fallback; refit сбрасывает обе калибровки.
- [x] Точные тесты рангов по каждой группе, независимости групп, lifecycle,
      валидации, ties и утечки данных; сверка с M/E2/1 по общим допускам.
- [x] Парный эксперимент pooled/grouped/oracle и FCFS, EASY/conservative;
      Erlang-2/lognormal шум, iid/slowdown, контроль ресурсной нагрузки,
      coverage и задержки всех ресурсных классов, независимые seed-наборы.
- [x] Отдельная проверка нехватки calibration на вложенных подвыборках;
      недоступные прогнозы показывать явно, не удалять заявки из очереди.
- [x] Отчёт, EN/RU документация, roadmap, быстрый/полный pytest,
      black/isort и pylint без новых замечаний.

## Результаты

Добавлены `calibrate_by_group`, явный grouped-режим `predict` и неизменяемые
диагностики `RuntimeGroupCalibration`; pooled/point API сохранён.
[Руководство EN](../msj_runtime_prediction.md#calibration-by-resource-group),
[отчёт](../research/msj-group-calibration-results-2026-10.md),
[команды и артефакты](../../works/msj_group_calibration/README.md).

Выполнены 672 scheduler-прогона и 96 prediction-only проверок размера calibration.
В iid/lognormal покрытие K=4 выросло с 90.03% до 95.33% на новых парных данных;
снижение нарушений обещаний не привело к снижению задержек широких заявок.
При n_cal=60 конечный прогноз K=4 недоступен во всех 12 повторах; при 100 —
доступен в 8 из 12. Подмены pooled-оценкой или удаления работ нет.
При slowdown2 grouped-покрытие lognormal падает до 81.12% в целом.

Проверки завершены 2026-10-02:

## Контракт и протокол до запуска

Группы — фиксированные неотрицательные целочисленные метки наблюдаемого ресурса,
не категории, подобранные по calibration/test длительности. На общей независимо
обученной log-linear модели использовать signed score предыдущего эпика.
Для группы g: n_g наблюдений, k_g=ceil((n_g+1)*coverage), свой k_g-й score.
При k_g>n_g диагностика показывает отсутствие конечной границы; прогноз для
этой группы отвергается, другие достаточно представленные группы доступны.
Неизвестная группа также вызывает ошибку. Существующая pooled-калибровка остаётся
явным отдельным режимом, не запасным обещанием group coverage.

Основная сетка: два закона остаточного шума EPIC-049, два режима (iid, slowdown2),
две нагрузки (0.35,0.55), FCFS и EASY/conservative с pooled95/grouped95/oracle.
12 новых независимых seed 50000–50011, train=1500, calibration=1000,
400 warm-up и 4000 измеряемых приходов: 672 scheduler-прогона.
Модель, train/calibration/test и actual work одинаковы для парного сравнения;
в slowdown S удваивается и λ уменьшается вдвое, без перекалибровки.
Отдельный prediction-only sweep calibration n=60,100,300,1000 на вложенных
префиксах одной когорты, с фиксацией доступности и покрытия по каждому классу.
Интервалы — Student по seed-наборам, разности парные; без поправки на множественность.

## Основание и границы

Angelopoulos, Bates, *A Gentle Introduction to Conformal Prediction and
Distribution-Free Uncertainty Quantification*,
[arXiv:2107.07511, §4.1](https://arxiv.org/html/2107.07511v6#S4.SS1):
group-balanced split-conformal по наблюдаемой группе X, не по неизвестному Y.
В терминологии MSJ это калибровка по ресурсным классам; метод Mondrian известен,
новизна conformal prediction не заявляется. Групповое покрытие требует обменности
calibration/test внутри группы при независимо обученном score и фиксированном
разбиении. Оно не является условным покрытием для каждого X, гарантией всех
заявок трассы, обещаний или p99. Малая выборка даёт грубые и нестабильные пороги.
Drift, возрастное обновление, реальные трассы и новые дисциплины вне этого эпика.
