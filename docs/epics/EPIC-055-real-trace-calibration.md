# EPIC-055: Калибровка обслуживания и проверка дисциплин на реальной трассе

- **Статус:** done
- **Создан:** 2026-10-02
- **Завершён:** 2026-10-02
- **Roadmap:** [Реальные трассы и калибровка](../roadmaps/real-trace-calibration.md)

## Цель

Первый этап трека 1: воспроизводимо проверить, сохраняют ли простые модели
длительности выводы о качестве существующих MSJ-дисциплин на исторических данных.
Новый планировщик и утверждение научной новизны не входят в эпик.

## Контракт до эксперимента

Источник — SDSC SP2, очищенная SWF-трасса 4.2 из Parallel Workloads Archive.
В среде прямой download архива возвращает HTML; используется явно обозначенная
копия DIR-LAB, закреплённая commit ID и SHA-256. Совпадение с байтами недоступного
оригинального download не утверждается. Данные не добавляются в git.

Исследуем только записи status=1 с положительным временем выполнения, известным
ожиданием и одинаковым запрошенным/выделенным числом узлов. Это условная выборка
завершённых работ, не весь кластер. K не округляется; capacity=128 фиксирована.
Wait применяется только для определения доступности истории, не переносится в
очередь симулятора. Длительность — наблюдаемое wall-clock время, не CPU demand.

Временная граница — 60% диапазона submit исходной трассы. История включает только
работы, завершившиеся строго до границы. После границы — первые три непересекающихся
блока по 1200 работ: 200 прогрева и 1000 измеряемых; каждый блок начинается пустым.
История фиксирована для всех блоков. Никакой перенормировки нагрузки по test S.

Фиксированные группы K: 1, 2–8, 9–32, 33–128. Модели обслуживания: эмпирическое
ресэмплирование истории, Exp по среднему, PH на основе первых двух моментов
(balanced H2 точно согласует их при CV²>1; Erlang сохраняет среднее и приближает
дисперсию при ограниченном числе фаз иначе), moment-lognormal.
Восемь seed 55000–55007; общий массив uniform для моделей и общий workload для
дисциплин. Контроль — replay зарегистрированных длительностей. Все генерируемые
модели iid внутри групп и потому не сохраняют зависимость соседних длительностей.

Дисциплины: FCFS, FirstFit, MSF, Adaptive Quickswap, EASY, conservative.
Прогноз для backfilling — фиксированный исторический p90 группы, одинаковый при
всех моделях; скрытый S не передаётся прогнозу. Прерывания исключены: в данных
нет измеренной стоимости checkpoint/resume.

Основная метрика — mean T; дополнительные mean W, p95/p99 T, K-взвешенный mean T,
показатели по ресурсным группам, загрузка и простой при очереди. Отдельно сравнить
рейтинг политик и потери от выбора по модели на контрольном replay.
MC-интервалы условны на истории и блоке, не являются интервалами для популяции
реальных нагрузок. Блоки не объявляются независимыми.

## Результаты

Добавлены `parse_swf` / `chronological_split` и `ServiceCalibration`;
[CLI эксперимента](../../examples/real_trace_calibration_experiment.py)
не меняет существующий API планировщиков.

Из 59 715 записей приняты 43 117; 16 598 отменённых исключены. История — 30 808
завершённых работ; ещё 23 не завершены строго до границы и не входят в обучение.
После границы доступны 12 286, для эксперимента использованы первые 3600.
Все четыре группы получили собственный H2-fit; fallback не потребовался.

Выполнены 594 предписанных расписания; повтор всех 594 дал побайтово одинаковый
JSON. Независимо пересчитаны 1008 обычных/парных MC-интервалов, разбиение сырой
трассы, параметры по группам и учёт групп всех 594 строк. Ещё 18 контрольных
replay проверены по сохранению работы, временам исполнения и лимиту 128 узлов.

Все четыре модели выбирают FirstFit по mean T во всех трёх блоках, но MAPE
задержек велик: 60–69% для mean T и 49–64% для p99 T. По p99 ни один из
12 модельных выборов не совпал с лучшим контрольным; на третьем блоке потеря
от выбора MSF вместо FirstFit равна 38.07%. Это результат условной исторической
когорты, не универсальный рейтинг дисциплин.

Проверки: 65 новых модульных тестов; полный pytest **1339 passed** (354.64 s),
быстрый **1330 passed** (255.83 s), в каждом 16 прежних предупреждений.
Black, isort и pre-commit пройдены; pylint новых модулей/эксперимента 10.00,
полный пакет сохраняет 43 прежних замечания, без новых.
Reader-проверка документации уточнила ретроспективность границы и приближённость
Erlang по дисперсии; ограничения не скрыты за термином «без утечки».
