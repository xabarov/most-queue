# EPIC-036: M/H2^[a,b]/1 с H2-подогнанным обслуживанием батча (CV≥1)

- **Статус:** done
- **Создан:** 2026-09-30
- **Roadmap:** [../roadmaps/bulk_service_general_h2_roadmap.md](../roadmaps/bulk_service_general_h2_roadmap.md)

## Цель

Дополнить EPIC-035 (Erlang-подгонка, CV<=1) комплементарным H2-случаем (CV>=1) для общего
времени обслуживания батча — то же механическое расширение CTMC фазовым измерением, теперь с
H2 (двухфазная смесь) вместо Erlang (последовательная цепочка фаз).

## Контекст

Обзор: [../research/bulk-service-general-h2-2026.md](../research/bulk-service-general-h2-2026.md).
Прямое продолжение EPIC-035 — та же техника (подгонка по моментам к фазовому семейству,
расширение существующей CTMC), теперь с H2 вместо Erlang. Структурно ПРОЩЕ Erlang: H2 —
«ветвление» (фаза выбирается один раз при старте батча, расщепляя переход на `×p1`/`×p2`), а не
последовательная цепочка фаз. `p1→1` (H2 вырождается в `Exp(mu1)`) — точная регрессия к уже
реализованному `BulkServiceMM1Calc`. Общий случай сразу совпал с независимой DES без ошибок (в
отличие от EPIC-035, где была найдена и исправлена ошибка `k²`).

## Результаты

Новый класс `BulkServiceH2Calc` (`most_queue/theory/batch/bulk_service_h2.py`) — точная
M/H2(p1,mu1,mu2)^[a,b]/1 очередь с групповым обслуживанием через усечённую CTMC над состоянием
`(размер батча i, фаза ∈ {0,1}, ожидающие j)`, где фаза выбирается один раз при старте батча
(«ветвление», а не последовательная цепочка, как у Erlang в EPIC-035) и расщепляет каждый переход
«батч стартует» на две взвешенные подставки `×p1`/`×p2`.

**Валидация:** `p1→1` (H2 вырождается в `Exp(mu1)`) точно совпадает с `BulkServiceMM1Calc`
(до float64-точности). Общий (двухфазный) случай проверен против независимой DES при трёх разных
`(p1,mu1,mu2)` — совпало с первой попытки, без ошибок (в отличие от EPIC-035, где была найдена и
исправлена ошибка `k²` в ставке перехода между фазами Erlang) — правдоподобное объяснение: у H2
«выбор фазы один раз при старте» структурно проще корректно закодировать, чем «последовательное
продвижение фазы» у Erlang.

**Тесты:** 6 новых (`tests/units/test_bulk_service_h2.py`) — точная регрессия `p1→1`, общий случай
против DES (3 параметризации), подгонка `set_servers_from_moments`, валидация параметров. Полный
набор тестов: 671 passed, 0 failed (782s).

**Документация:** `docs/models/batch.md`+`.ru.md` — новая подсекция «General/Общее (H2-fitted/
H2-подогнанное) batch-service time (CV ≥ 1)», рядом с Erlang-подсекцией EPIC-035; `docs/models.md`/
`.ru.md` — новая строка в каталоге.

**Объём (честно задокументирован):** только среднее (`E[V]`, `E[W]` через закон Литтла), тот же
начальный объём, что EPIC-035 для Erlang-случая. Резерв (не в этом эпике): точные моменты выше
среднего (нужен PASTA-аргумент, отслеживающий фазу батча в момент прихода); batch-size-зависимые
параметры H2; единый диспетчер `set_servers_from_moments` с авто-выбором Erlang/H2 по CV поверх
`BulkServiceErlangCalc` и `BulkServiceH2Calc`.
