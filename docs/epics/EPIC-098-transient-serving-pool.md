## Задача и границы

Рассчитать влияние кратковременного всплеска на вероятность длительного ожидания
свободного слота. Пуассоновский поток с кусочно-постоянной интенсивностью,
постоянный предел числа активных заявок, экспоненциальные завершения с интенсивностью,
зависящей от занятости, внешняя бесконечная очередь FCFS. Начальное состояние задано.

Используется известная finite state projection с поглощающим состоянием первого
выхода. Вероятности не нормируются после усечения. Масса выхода ограничивает
ошибку ограниченных функционалов; закон ожидания при известном числе заявок —
Эрланга с насыщенной интенсивностью завершений. Арифметика floating point,
округления не сертифицированы. Это не токеновая модель и не прогноз TTFT GPU.

## Результат реализации

- `TransientOccupancyQueueCalc`, подкласс стандартных результатов, проверки
  входных данных, ограничение размера области, диагностика сохранения массы.
- `population_tail_bounds()` и `waiting_tail_bounds()` на заданной сетке времени.
- Аналитические частные случаи, независимый событийный эксперимент,
  вложенность областей и корректное прохождение смен интенсивности.
- [Пример](../../examples/llm_burst_recovery.py),
  [полный вывод и API](../models/transient-occupancy.md),
  [русское описание](../models/transient-occupancy.ru.md), сохранённые графики и JSON.
- README EN/RU, каталог моделей, ссылки семейств, CONTRIBUTING и формы issue.
- План калибровки, SLO и распространения; фактическая оценка письма XERJ.

При всплеске с 2-й до 5-й секунды риск ждать слот дольше 0,5 с в момент 5 с
равен примерно 90,25% для четырёх слотов и 34,79% для восьми. На сетке 0,05 с
риск становится ≤ 5% и остаётся таким до 14 с начиная с 10,25 и 6,35 с.
Параметры синтетические, пределы области 64 и 96; ошибка усечения меньше 7,33e-9.

отдельный обязательный прогон без `slow`: **3508 passed, 16 warnings, 427,34 с**.

всей библиотеки — 9,98/10, замечания находятся в неизменённых модулях.
Проверены локальные ссылки, YAML форм issue, JSON и размеры новых артефактов.

Wheel и sdist собраны локально. Wheel установлен с зависимостями в новое
окружение Python 3.11.15. Импорт и расчёт выполнены вне исходников, затем
запущен пример из `examples/`; его JSON полностью совпал с сохранённым.
Набор зависимостей этой проверки: NumPy 2.4.6, SciPy 1.17.1, Matplotlib 3.11.2.
