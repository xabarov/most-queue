# EPIC-047: MSJ с PH-обслуживанием и EASY backfilling

- **Статус:** done (2026-10-02)
- **Создан:** 2026-10-01
- **Roadmap:** [msj-ph-backfilling.md](../roadmaps/msj-ph-backfilling.md)

## Цель

Выполнить первый законченный этап направления MSJ из
[обзора](../research/realistic-queueing-research-directions-2026-10.md): изучать влияние
неэкспоненциального обслуживания, связи потребности в ресурсах с длительностью и
информации о времени выполнения на FCFS/EASY. Старый экспоненциальный API сохранить.

## Контекст

Выделено из MSJ-части [EPIC-044](EPIC-044-non-exponential-machine-repair-msj.md).
Machine repair остаётся в EPIC-044. Аналитика нового эпика — перечисление состояний
малой PH-CTMC с конечным усечением, а не воспроизведение матрично-геометрического
алгоритма статьи Anggraito et al. и не точное решение произвольного G.

Источники:

- Anggraito et al., *The Multiserver Job Queuing Model with two job classes and
  Cox-2 service times*, Performance Evaluation, 2025,
  [DOI 10.1016/j.peva.2025.102486](https://doi.org/10.1016/j.peva.2025.102486).
- Grosof et al., *The RESET and MARC techniques, with application to multiserver-job
  analysis*, [Performance Evaluation](https://www.sciencedirect.com/science/article/pii/S0166531623000482):
  насыщенная система, PH и зависимые server need/duration.
- Tsafrir, Etsion, Feitelson, *Backfilling Using System-Generated Predictions Rather
  Than User Runtime Estimates*, IEEE TPDS, 2007,
  [DOI 10.1109/TPDS.2007.70606](https://doi.org/10.1109/TPDS.2007.70606).

## Задачи

- [x] Проверить существующие модели и литературу, согласовать scope.
- [x] PH-калькулятор FCFS: ожидание/пребывание по классам, распределение числа
      заявок, загрузка, граничная масса и численная невязка.
- [x] PH-насыщенная система и проверка FCFS-устойчивости; не подменять её
      необходимым условием `sum(lambda_i * k_i * E[S_i]) < k`.
- [x] DES общего обслуживания и неизменяемые трассы для FCFS/EASY; генераторы
      библиотеки и явно заданные оценки длительности.
- [x] EASY: резервирование головы, запрет скрытого знания будущей длительности,
      обработка заниженных прогнозов без уничтожения работ, счётчик нарушений.
- [x] Средние/моменты, эмпирические p95/p99 по классам, занятость ресурсов и
      простой при непустой очереди; полное завершение измеряемой когорты.
- [x] Детерминированные тесты расписаний, PH/Exp-редукции, CTMC/DES и контроль
      усечения; валидация входов и защита от взрыва числа состояний.
- [x] Воспроизводимый эксперимент: FCFS/EASY, формы обслуживания, зависимость
      K/S, oracle/ошибочные оценки, независимые повторы и интервалы разностей.
- [x] Документация EN/RU, примеры, каталог; быстрый и полный pytest, форматирование,
      отсутствие новых замечаний pylint.

## Критерии готовности

Общий [DoD](../DOD.md). Неизвестные аналитические высшие моменты не заполняются нулями.
Little's law в усечённой системе использует принятую, а не предложенную интенсивность.
Граничная масса — диагностика усечения, не доказанная граница ошибки.
Результаты эксперимента не объявляются доказательством универсального выигрыша EASY.

## Результаты

Реализованы:

- [MsjPHCalc](../../most_queue/theory/msj/ph.py): реальная PH по каждому классу,
  насыщенный порог, конечная FCFS-CTMC, проверка применимости и диагностика усечения.
- [MsjGeneralSim / MsjTraceJob](../../most_queue/sim/msj_general.py): генераторы G,
  immutable trace replay, FCFS/EASY, явная информация о длительности, обработка
  превышения прогнозов и статистика когорт/ресурсов/резервирований.
- [Методика](../msj_ph_methods.md), каталог EN/RU, ссылки из руководств симуляции,
  стандартный интерфейс BaseQueue и независимые CTMC/DES-тесты по шаблонам проекта.
- [Эксперимент](../../examples/msj_backfilling_experiment.py): 144 прогона;
  [данные](../../works/msj_backfilling/results.json) и
  [разбор результатов](../research/msj-ph-backfilling-results-2026-10.md).

Проверки 2026-10-02:

- Полный финальный `pytest tests/ -n auto -q --tb=short`: **839 passed**, 16
  предупреждений из существующих модулей, 388.03 с.
- Финальный целевой набор PH/DES/эксперимента: **62 passed**; также отдельно
  пройдены обновлённые Cox-2-случаи и не минимальное PH-представление Exp.
- Промежуточный `pytest tests/ -m "not slow" -n auto`: **816 passed** до добавления
  последних проверок; полный финальный набор включает и эти, и новые проверки.
- `black --check`, `isort --check-only`, `git diff --check` — пройдены.
- Полный `pylint most_queue` сравнен с архивом исходного `cee3e9f`: 43 замечания
  до и после, **новых 0**. Новые модули отдельно проходят pylint без замечаний.
- Все Python-примеры страницы модели EN исполнены, относительные ссылки проверены.
- Дополнительно 10 случайных oracle-трасс по 1000 заявок: сохранение ёмкости,
  неотрицательные ожидания, нормировка occupancy и отсутствие нарушений обещаний.

На выбранном coupled/lognormal-сценарии E[T]: 8.1622 (FCFS), 3.7672 (EASY-oracle),
3.9869 (noisy), 4.9348 (class-mean). Это синтетический пилот, не универсальное
доминирование и не гарантия хвоста. Для широких задач улучшение p99 существенно
меньше агрегированного; ошибка прогнозов нарушает резервирование. Аналитические
высшие моменты, conservative backfilling и реальные трассы остаются в явно
выделенном следующем этапе roadmap, а не объявляются выполненными.
