# Roadmap: M/M/1 с точным admission control по дедлайну (Exp(θ))

> Источники, отвергнутая гипотеза и вывод — `docs/research/llm-serving-deadline-admission-control-2026.md`.

## 1. Модель

M/M/1 (Poisson(λ), Exp(μ)), FCFS-порядок сохраняется (не EDF). Каждый клиент несёт случайный
относительный дедлайн `D ~ Exp(θ)` (независимо). При приходе клиент наблюдает текущую загрузку
`U` (workload, PASTA) и **принимается** (по-прежнему FCFS) тогда и только тогда, когда `D > U` —
иначе немедленно отклоняется (не встаёт в очередь вообще, не reneging).

## 2. Функциональное уравнение (level-crossing, Takács-style)

Для плотности `f(x)` стационарного `U`, `pi0=P(U=0)`:

```
f(x) = λ·pi0·e^{-θ·0}·e^{-μx}  +  λ·∫_0^x e^{-θu}·f(u)·e^{-μ(x-u)} du
```

Преобразование Лапласа-Стилтьеса `phi(s)=E[e^{-sU}]` (включая атом `pi0`), с учётом
`tail_D(u)=e^{-θu}` (сворачивает взвешенное преобразование в сдвиг `phi(s+θ)`):

```
phi(s) = pi0 + [λ/(s+μ)] · phi(s+θ)
```

Рекурсия по сдвигу `θ` телескопируется в быстро сходящийся ряд (сходится при ЛЮБЫХ λ,μ,θ>0 —
знаменатели растут как `(nθ)!`-подобно, система всегда устойчива, т.к. приход при большой загрузке
автоматически отклоняется):

```
phi(s) = pi0 · Σ_{n=0}^∞  λ^n / Π_{j=0}^{n-1}(s + jθ + μ)
pi0 = 1 / Σ_{n=0}^∞ λ^n / Π_{j=0}^{n-1}(jθ + μ)
```

`loss_prob = 1 - phi(θ)` (т.к. `phi(θ)=E[e^{-θU}]=E[tail_D(U)]=P(D>U)` по PASTA — доля принятых).

## 3. Отвергнутая гипотеза (см. research-доку) — не пытаться снова

`n`-based цепь рождения-гибели с `P(admit|n)=(μ/(μ+θ))^n` (используя `Erlang(n,μ)` как загрузку
при `n` в системе) — САМА формула верна изолированно, но `n` НЕ является достаточной статистикой:
обусловливание на факте приёма смещает распределение загрузки через НЕконстантный вес `tail_D(w)`,
и это смещение не стирается памятью-less обслуживания (только «время с последнего перехода»
стирается memorylessness, а не обусловливание на прошлом сравнении). Численно поймано: emp.
`P(admit|n)` систематически отличается от формулы (хуже с ростом `n`), устойчиво по сидам.

## 4. Точные моменты через усечённый степенной ряд (Тейлор по `s`)

Чтобы получить моменты `E[U^k]` без ошибки численного дифференцирования, `phi(s)` вычисляется как
УСЕЧЁННЫЙ СТЕПЕННОЙ РЯД по `s` (арифметика усечённых рядов: умножение — свёртка, обратный элемент
— стандартный рекурсивный алгоритм деления степенных рядов), а не через конечные разности.
`C_n(s)=Π_{j=0}^{n-1}(s+jθ+μ)` — произведение ЛИНЕЙНЫХ по `s` рядов; `1/C_n(s)` — через
`series_reciprocal`. Коэффициент при `s^k` в разложении `phi(s)` связан с моментом:
`E[U^k] = (-1)^k · k! · [коэффициент при s^k]` (стандартное свойство ПЛС).

Для моментов **при условии приёма** — тот же приём, но раскладываем `phi(s+θ)` по `s` (т.е.
`C_n(s)=Π_{j=0}^{n-1}(s+θ+jθ+μ)`, начальное смещение `offset=θ`):

```
E[U^k · e^{-θU}] = (-1)^k · k! · [коэфф. при s^k в разложении phi(s+θ)]
E[U^k | admitted] = E[U^k · e^{-θU}] / phi(θ)
```

Момент пребывания принятого клиента `V=U+S`, `S~Exp(μ)` — рисуется ПОСЛЕ решения о приёме,
независимо от `U` и события приёма → `conv_moments(E[U^k|admitted], E[S^k])` (уже есть в
библиотеке).

Проверено: `pi0`, `loss_prob`, `E[U]`, `E[U|admitted]`, `E[V|admitted]`, `E[V^2|admitted]` — все
совпадают с независимой (от нуля написанной, непрерывный workload-процесс, НЕ `n`-based) DES в
пределах MC-погрешности (3 сида).

## 5. API

```python
class MM1DeadlineAdmissionControlCalc(BaseQueue):
    def __init__(self, num_terms: int = 150, calc_params: CalcParams | None = None): ...
    def set_sources(self, l: float): ...
    def set_servers(self, mu: float): ...
    def set_deadline(self, theta: float): ...  # D ~ Exp(theta)
    def get_u_moments(self, num: int = 4) -> list[float]: ...       # unconditional workload
    def get_u_moments_admitted(self, num: int = 4) -> list[float]: ...
    def get_loss_prob(self) -> float: ...
    def run(self, num: int = 4) -> QueueResults: ...  # v/w = admitted-conditional sojourn/wait
```

`num_terms` — усечение ряда (сходится быстро; 150 членов с большим запасом для разумных
λ,μ,θ — проверить остаточный член).

## 6. Sim

`MM1DeadlineAdmissionControlSim`: непрерывный workload-процесс `U(t)` (НЕ `n`-based!), убывает с
единичной скоростью между событиями, приход (Poisson λ) сравнивает свежий `D~Exp(θ)` с текущим
`U`; при приёме `U += Exp(μ)`. Считает `pi0`, `loss_prob`, моменты `V` принятых.

## 9. Резерв

- Общий (не экспоненциальный) дедлайн `G` — `Ψ(s)` не сворачивается в сдвиг `phi`; нужен другой
  численный метод (напр. прямая дискретизация интегрального уравнения Вольтерра).
- Многоканальный (`c>1`) admission control.
