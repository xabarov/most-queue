## 1. Разница с (0,S)

В `(0,S)` пополнение (ставка `θ`, переход `i → S`) срабатывает только при `i=0`. В общей `(s,S)`
— при **любом `i ≤ s`** (`0 ≤ s < S` — точка перезаказа). Благодаря отсутствию памяти у `Exp(θ)`
«заказ уже в пути» полностью описывается условием `i ≤ s` — отдельный бит состояния не нужен (см.
research-доку §3 для полного обоснования).

**Важно:** порог блокировки обслуживания и порог lost-sales (`policy="lost_sales"`) остаются
`i=0` — это **другой** порог, не совпадает с `s`. При `1 ≤ i ≤ s` заказ уже размещён, но запас
физически есть — обслуживание идёт нормально.

## 2. Изменение QBD-блоков (относительно (0,S))

```
(0,S):    A1[0, S] = θ                         (только i=0)
(s,S):    A1[i, S] = θ   для всех i = 0..s      (i<=s)

(0,S):    A1[i,i] = -(λ+μ)   для i = 1..S
(s,S):    A1[i,i] = -(λ+μ+θ) для i = 1..s        (обслуживание ещё возможно, И заказ уже в пути)
          A1[i,i] = -(λ+μ)   для i = s+1..S      (без изменений)

A1[0,0]:  как в (0,S)/lost-sales (без изменений — порог блокировки/lost-sales = 0, не s)

B00 — симметрично A1, но без слагаемого μ (n=0, обслуживать нечего):
(s,S):    B00[i, S] = θ   для i = 0..s
          B00[i,i] = -(λ+θ) для i = 1..s   [lost_sales: без λ при i=0, как раньше]
          B00[i,i] = -λ     для i = s+1..S
```

`A2` (обслуживание), `B01=A0`, `B10=A2` — без изменений.

**Проверка на s=0:** диапазон `i=1..s` пуст при `s=0`, диапазон пополнения `i=0..s` вырождается в
`{0}` — формулы точно совпадают с уже реализованной `(0,S)`-моделью. Это — основной
regression-тест (не приближённое совпадение, а точное per construction).

## 3. API

```python
class MM1QueueingInventoryCalc(BaseQueue):
    def __init__(self, s_max: int, s: int = 0, policy: Policy = "backorder",
                 calc_params: CalcParams | None = None):
        """:param s: reorder point, 0 <= s < s_max (default 0 -- the (0,S) policy)."""
```

Валидация: `0 <= s < s_max` (иначе `ValueError`).

## 4. Sim

`MM1QueueingInventorySim` получает параметр `s`; условие пополнения `i == 0` → `i <= s`
(единственное изменение в событийной логике, симметрично теории).
