## Что изменилось

| Характеристика основного текста | Полная редакция | Вторая редакция |
|---|---:|---:|
| Страниц PDF, включая аннотации и литературу | 17 | 7 |
| Нумерованных формул | 12 | 4 |
| Таблиц | 7 | 2 |
| Рисунков | 7 | 2 |

Сокращены аннотации, введение и описание метода. Основная линия изложения:
модель → три исхода ожидания → условный и безусловный критерии → расчёт
вероятностей → два численных результата. Первый результат показывает, почему
уменьшение среднего ожидания среди дождавшихся не гарантирует роста доли
своевременно начавших обслуживание среди всех поступивших. Второй показывает,
как приближение распределения меняет допустимость параметров и выбор размера
пакета. Для выбора оставлены два показательных примера из полной таблицы.

В приложение перенесены конструкция цепи и схемы переходов, локальная оценка
погрешности с доказательством, формулы моментов, подробности численной схемы,
таблицы проверок, дополнительные графики, полный набор примеров выбора,
сопоставление с моделью Inoue и обзорная таблица литературы. Приложение занимает
12 страниц PDF и читается отдельно по мере необходимости.

В основном тексте сохранены ограничения точности, увеличение числа ошибочных
признаний допустимости при учёте атома в нуле, невыполнение критерия сходимости
в трёх вспомогательных вариантах и два расхождения с доверительными интервалами.
Локальная оценка не представлена как оценка полной погрешности.

По последнему уточнению автора во второй редакции используется **«помеченная
заявка»**, в том числе на схеме переходов. Предпочтение записано также в skill
и словаре; текст сохранённой полной редакции не менялся.

## Повторная сборка

Команды выполняются из этого каталога. Требуются XeLaTeX, latexmk, Biber,
шрифты PT Serif и DejaVu Sans Mono; для Word — Python, uv, Pandoc и lxml.

```bash
cd latex
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex appendix.tex
cd ..
uv run --no-project --with lxml --with pypandoc_binary python build_word.py
```

Рисунки и библиография включены в этот каталог. При изменении схемы ожидания
её можно пересобрать скриптом `build_tagged_diagram.py` в окружении с matplotlib.
Скрипты этой редакции записывают результаты только в её собственный каталог.
Сборка полного варианта и повторный запуск расчётных серий для этих правок
не требуются. Приватный статус рукописи сохранён.
