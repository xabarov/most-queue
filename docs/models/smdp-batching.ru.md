# Управление запуском пакета как SMDP

[English version](smdp-batching.md) · [Каталог](../models.ru.md)

Воспроизведение конечной overflow-аппроксимации
[Xu, Sun, Zhou, Niu, arXiv:2301.12865v3](https://arxiv.org/html/2301.12865v3)
и отдельная имитация **неограниченной** очереди. Оптимум конечной модели
не гарантирует ни оптимальности, ни устойчивости перенесённой политики.

## Простыми словами

При освобождении сервера запустить пакет сейчас или дождаться следующего
запроса? Большой пакет амортизирует энергию запуска, но увеличивает ожидание.
Обслуживание детерминированное и зависит от размера, а не экспоненциальное.
Интервалы между решениями различны: стоимость на решение — неверный критерий;
нужна стоимость на единицу физического времени.

## Контракт и API

Один nonpreemptive прибор, Poisson λ>0, максимум пакета B. Профили задают
положительные времена τ_b и неотрицательные энергии ζ_b, b=1,...,B.
В статье профили аффинные; произвольные конечные профили — расширение API,
не теорема о пороговой структуре. Требуется λ<max_b(b/τ_b).
Веса неотрицательны, хотя бы один положителен; baseline idle power не задан.
Критерий: w1 × средний отклик + w2 × средняя мощность.

```python
from most_queue.theory.batch import BatchSmdpCalc

model = BatchSmdpCalc(40, energy_weight=4, overflow_cost=100)
model.set_sources(1.0)
model.set_servers([0.4, 0.6], [1.0, 1.3])
r = model.run(tolerance=1e-8)
assert r.converged
print(r.average_cost, r.policy)
print(r.overflow_cost_rate, r.tail_drift, r.tail_extension_stable)
```

Состояния 0,...,N — число запросов в момент решения при свободном приборе.
Отдельная overflow-метка N+1 **представляет число N**, не N+1 и не ёмкость
буфера. Численные ограничения: 1≤N≤2000, 1≤B≤min(N,128).
Действие 0 ждёт следующего прихода, не фиксированного таймера; a>0 запускает
a запросов. Все запросы пакета остаются в системе до общего завершения.

При a=0 переход s→s+1, средний интервал 1/λ, площадь населения s/λ,
стоимость w1*s/λ²; overflow самозацикливается.
При a>0 переход s→s−a+K, K~Poisson(λτ_a); хвост выше N идёт в overflow.
Площадь sτ_a+λτ_a²/2, стоимость
w1*(sτ_a/λ+τ_a²/2)+w2*ζ_a. Overflow подставляет s=N и добавляет c_o × интервал.
`epoch(s,a)` возвращает строку переходов, среднее время, стоимость, площадь, энергию.

Uniformization: η строго меньше ограничений статьи, по умолчанию
0.9 × минимальный средний интервал. RVI останавливается по span приращений;
при равенстве выбирается меньшее действие. `run` принимает `max_iterations`
и `eta`; исчерпанный лимит явно даёт `converged=False`, не «оптимум».
Корреляции Poisson устраняют O(BN²) тензор переходов: память RVI O(BN),
арифметика O(BN²) на итерацию. Финальная оценка политики использует плотную
O(N²) систему. `evaluate_policy(actions)` работает без RVI. Возвращаемый
`bias` масштабирован обратно к исходной SMDP.

| Поле | Значение |
|---|---|
| `average_cost`, `response_proxy`, `power` | Конечные стационарные reward-ratios на физическое время |
| `decision_pmf`, `mean_epoch_time` | Распределение по эпохам решений и средний интервал |
| `interval_time_weights` | μ_s*y_s / sum(μ*y), **не** временной PMF реального населения |
| `overflow_cost_rate` | Δ=μ_overflow*c'_overflow / sum(μ*y); не граница ошибки |
| `gain_lower`, `gain_upper`, `bellman_residual`, `balance_residual` | Численные диагностики конечной модели |
| `policy`, `bias`, `iterations`, `converged`, `uniformization_eta` | Действия, исходный SMDP bias, состояние решателя |
| `tail_drift`, `tail_extension_stable` | Отдельная проверка постоянного действия выше N в реальной очереди |

Для постоянного хвостового a>0 дрейф по завершениям λτ_a−a.
Строгая отрицательность даёт Foster-аргумент устойчивости только для указанного
Poisson/deterministic расширения. Действие 0 выше N означает вечное ожидание
с дрейфом +1 по приходам. Малый Δ/невязка Bellman эту проверку не заменяет.
Замена хвостового действия создаёт **другую политику**: её реальная стоимость
не равна исходному конечному gain. Пороговая структура не навязывается.

Унаследованные `w`, `v`, `p`, `pi`, utilization остаются None: моменты задержки
и временное распределение числа запросов не решены.

## Независимая имитация

```python
from most_queue.sim.smdp_batching import BatchSmdpSim

sim = BatchSmdpSim(seed=42, energy_weight=4)
sim.set_sources(1.0)
sim.set_servers([0.4, 0.6], [1.0, 1.3])
s = sim.run(20000, r.policy, warmup=2000)
assert s.initial_jobs + s.arrived == s.completed + s.unfinished
assert abs(s.total_population_area - s.completed_residence
           - s.unfinished_residence) < 1e-6
```

Политика — N+2 допустимых целых действий (последнее применяется ко всем
реальным состояниям выше N), либо callable реального населения. Имитация
не обрезает очередь, не отвергает overflow и не импортирует решатель.
FCFS хранит времена прихода запросов. Приход во время обслуживания не вызывает
решения; при совпадении сначала завершение, затем приходы и новое решение.
Каждый запуск сбрасывает seeded RNG приходов.

`run(horizon, policy, warmup=0, arrivals=None, initial_jobs=0,
record_trace=False, max_events=2000000)` допускает отсортированный replay времён
в [0,horizon), включая совпадения. Начальные запросы имеют время прихода 0.
Нет drain; события точно на границе горизонта исключаются. Trace хранит решения.

Полные счётчики и экспозиции удовлетворяют двум тождествам примера, включая
незавершённые активные запросы. `population_area`, `power`, `busy_fraction`,
`response_proxy`, `average_cost` исключают warmup. Энергия — импульсная стоимость,
полностью начисляемая **при старте** пакета, включая пересекающие горизонт;
это не измерение энергии частично выполненного обслуживания. Полная `energy`
включает warmup, `power` учитывает только наблюдаемые старты. Прокси отклика —
наблюдаемая ∫Q(t)dt/(λ × длительность), не uncensored выборочное среднее latency
и не доказательство стационарности. `w`/`v` и временной PMF не возвращаются.

## Проверки и границы

[Отчёт](../research/smdp-batching-validation-2026.md),
[воспроизводимый JSON](../research/smdp-batching-results-2026.json): независимый
occupation LP, перебор политик, Poisson-суммы, квадратура площади, проверки
uniformization/bias, replay-балансы, угол M/D/1 и unbounded DES.
Опубликованный P4-профиль — вход численной репликации, не новые GPU-измерения.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m examples.smdp_batching_experiment
```

Нет hard SLO, случайного обслуживания, token/KV динамики, общего infinite
optimum или сертифицированной ошибки усечения. Механика Л4/Л5 и стоимость
Л3 здесь не объединены: слой синтеза диссертации остаётся незакрытым.
