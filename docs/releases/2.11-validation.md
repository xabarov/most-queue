# Подготовка и проверка Most-Queue 2.11

Дата: 14.11.2026. [Описание выпуска](2.11.md),
[публикация](publishing.md), [план LLM/GPU](../roadmaps/llm_gpu_growth_roadmap.md).

## Версия и состав

Последний опубликованный пакет перед этой работой — 2.9. Публичный тег v2.10
уже существует на `46e84681e6fa20a7531b00f33019edb820967192`; он сохранён.
Текущий выпуск получил номер 2.11 в `pyproject.toml` и `CITATION.cff`.

Включены EPIC-098, EPIC-099 и ранее накопленные изменения с 2.9. Описание
выпуска разделяет новые возможности и исправления, из-за которых следует
пересчитать прежние численные результаты. Материалы статей не редактировались.

## Научные и программные проверки

- EPIC-098: аналитические частные случаи, ошибка усечения, независимый DES,
  пример восстановления после всплеска; 55 целевых тестов семейства.
- EPIC-099: 49 целевых тестов импорта, совместных исходов, цензурирования,
  проверки ранга/профиля и восстановления параметров по отдельному токеновому
  DES; SHA256 всех девяти открытых файлов проверены.
- Реальный калибровочный пилот: train30/heldout15, ошибки TTFT 63,40% и TPOT
  9,18%; цель ≤15% по каждой метрике не пройдена. Этот результат не скрывается
  и не заменён подгонкой на проверочной выборке.
- Серверное ожидание в открытой выборке не наблюдается. Калибровка очереди,
  предсказания под нагрузкой и новые GPU-прогоны не заявляются выполненными.

Итоговые прогоны после завершения изменений кода:

- Полный: `pytest tests/ -q -n 12` — **3575 passed, 19 warnings**, 743,04 с.
- Без медленных: `pytest tests/ -m 'not slow' -q -n 8` —
  **3557 passed, 19 warnings**, 611,85 с.
- Для обоих запусков: `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=.`.
- Black и isort проходят для всех новых Python-файлов. В новых файлах нет
  замечаний pylint. Общий pylint: 9,97/10; замечания остаются в незатронутых
  модулях, включая срабатывания статического анализа NumPy/SciPy.
- Проверены локальные ссылки в 26 Markdown-документах, разбор JSON/YAML/CFF,
  состав добавляемых файлов и отсутствие токена PyPI в изменениях.

## Упаковка и публикация

Релиз собран из коммита `6205e87cc081199277fa8cc960a05448ea4497b3`,
на который указывает неизменяемый тег `v2.11`. Исходники для сборки извлечены
через `git archive`; wheel собран из полученного sdist с hatchling 1.33.0.
Оба дистрибутива прошли `twine check`. Проверены наличие новых модулей и
отсутствие окружения, учётных данных и временных файлов в архивах.

В отдельном окружении Python 3.12, вне рабочего репозитория, проверены версия
и источник импорта, классическая M/M/n/r, нестационарная модель и совместный
SLO. Оба примера запущены с установленным wheel; их JSON совпадают с сохранёнными
отчётами с допуском `rtol=1e-9, atol=1e-11`. `pip check` не выявил конфликтов.

14.11.2026 опубликованы:

- [PyPI 2.11](https://pypi.org/project/most-queue/2.11/), оба файла загружены
  в 12:28 UTC; SHA256 из публичного PyPI JSON совпадают с локальной сборкой.
- [GitHub Release v2.11](https://github.com/xabarov/most-queue/releases/tag/v2.11),
  с wheel, sdist и [SHA256SUMS](https://github.com/xabarov/most-queue/releases/download/v2.11/SHA256SUMS).
- После публикации выполнена новая установка `most-queue==2.11` непосредственно
  из PyPI в ещё одно чистое окружение; расчёты, импорты и `pip check` проходят.

Этот выпуск загружен через twine с локальным токеном из игнорируемого `.env`.
Workflow `publish.yml` подготовлен для будущего Trusted Publisher;
привязка Trusted Publisher на стороне PyPI в этой работе не настраивалась.
Итоговый отчёт обновлён отдельным коммитом после выпуска; тег и дистрибутивы
не изменялись.

## Воспроизводимость

Исходные измерения хранятся в `tests/fixtures/serving_measurements/flash_next/`
с лицензией и манифестом. Итоговые JSON и графики доступны в документации;
примеры не требуют сети или GPU. Они входят в исходный репозиторий, но не
в wheel/sdist библиотеки. Устанавливаемый пакет проверяется вне checkout.

Контрольные суммы выпуска публикуются отдельным `SHA256SUMS` вместе с
дистрибутивами; их нельзя включить в тот же пакет без циклической зависимости.
Токены публикации не входят ни в исходники, ни в артефакты.
