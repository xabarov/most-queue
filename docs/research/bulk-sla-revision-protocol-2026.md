# Протокол переработки — зафиксирован до публикационных прогонов

2026-10-12. Базовая зависимость среднего `g(s)=0.1438s+1.8874`.
Единица времени условная (для исходной калибровки Inoue — миллисекунда),
lambda имеет обратную единицу. Не используем неподтверждённую LLM-калибровку.
FIFO, бесконечная очередь, атомарные пакеты, независимое терпение Exp(gamma)
только до запуска. Никакого физического буфера потерь в постановке.

## Гипотезы и показатели

H1: среднее ожидание среди дождавшихся не определяет вероятность своевременного
запуска среди всех входящих. Проверять три исхода: запуск до D включительно,
запуск после D, уход. Возможный немонотонный успех не предрешён.
H2: сохранение атома в нуле при моментной подгонке может улучшать решения SLA;
положительный результат не гарантирован. Обе аппроксимации — gamma по двум
моментам, обычная и для положительной части с исходным весом.
H3: конечный cap и вариабельность — разные эффекты; не сравнивать ожидание
в очереди с границей полного времени Inoue и не называть это опровержением.

## Фиксированные панели

1. Нетерпение: lambda=.8, a=2, b=8; E3 и H2 с CV=1.5;
   gamma=0,.02,.05,.1,.25,.5; D=5,10,20. Для всех 12 случаев независимая DES:
   12 повторов, seeds=12000..12011, 100000 учётных приходов после 20000
   разогревочных. Приходы продолжаются до разрешения всех учётных исходов;
   нет цензурирования хвоста. Среднее и Student-t 95% interval по повторам,
   а не биномиальный интервал по зависимым заявкам. Редкие хвосты <1e-4
   не считаем верифицированными имитацией.
2. Нагрузка/порог/вариабельность: b=8, gamma=0, a=1,2,4;
   lambda*g(8)/8=.3,.6,.85; E10, E3, Exp, H2(CV=1.5). Всего36 случаев.
   Сравнить средние, атом и хвосты при D=5,10,20. Предельная нагрузка
   lambda*g(b)/b не равна фактической доле занятости.
3. Решения: lambda=.8, b=2..16 (все целые), a=1..min(4,b),
   E3/H2(CV=1.5), gamma=0,.1, D=5,10,20; targets=.01,.001,.0001 для
   условного хвоста и .1,.05,.01 для безусловной вероятности неуспеха.
   Всего228 случаев. Минимум b определяется для фиксированных a/family/gamma/D
   по точечному выполнению требования; не требуется, чтобы все большие b
   также удовлетворяли SLA. Отдельно ложное принятие/отказ и разница cap
   для двух moment baselines. Неразличимость с порогом в пределах 1e-7
   классифицировать отдельно, не объявлять выигрышем.
4. Inoue: lambda=.2,.8, a=1, gamma=0, детерминированное g(s);
   unbounded DynamicBatchingCalc и независимая DES для cap=4,8,16,32
   и unbounded (10 сценариев), seeds=13000..13011, тот же размер выборки.
   Метрика — полное время до завершения, дополнительно ожидание. Граница
   Inoue относится только к unbounded deterministic модели. Влияние CV
   оценивается отдельно панелью2. Не применять границу к finite cap.

## Точность, отказы и воспроизводимость

Для стационарных весов N=200,400,800,1600; минимум две соседние сетки.
Остановка при max абсолютном изменении средних/хвостов/уходов <=1e-7
и краевой массе <=1e-10. Эти критерии диагностические, не строгие bounds.
Хранить каждый attempt, N, краевую массу, потоковый residual, runtime.
При недостижении критерия до N=1600 — явный отказ/неразрешённый случай,
не молчаливая подмена результата. Не строить вывод по числам <1e-7.
Дополнительный float-check: агрегированная и per-state реализации в
регрессиях, баланс строк/неотрицательность и общая вероятность исходов.
За пределами этих проверок machine rounding не сертифицирован.

Для tagged-счётчика C: локальная вероятность выхода до собственного ухода
<=1e-13. При gamma>0 допускается опустить начальные состояния суммарного
веса <=1e-13; их погрешность учитывать отдельно. При gamma=0 behind-count
насыщается точно на a-1, начальные состояния не отбрасываются. Бюджет
300000 tagged states, C<=4096. Отказы сохранять, протокол не менять ради
красивого результата. Любое дополнение обозначать exploratory.

Сохранять JSON, параметры, seeds, версии пакетов, кодовый SHA-256,
SHA-256 протокола, времена и все отказы. Старые JSON не перезаписывать.
Таблицы/рисунки строить только из нового единого набора данных.
Имитационные интервалы — sampling diagnostics, не доказательство общей
ошибки, устойчивости или новизны. Benchmark speedup не заявляется.
