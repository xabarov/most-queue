# Словарь терминов: теория очередей (EN → RU)

Накапливается по мере работы над статьями в `docs/статьи/`. Цель -- одинаковый перевод одного и
того же понятия во всех статьях (не изобретать синоним заново в каждой новой статье). При
добавлении нового термина проверяй, нет ли уже близкого по смыслу эквивалента в этом списке.
Отмечай вариативность, если устоявшихся переводов несколько (с пометкой, какой предпочтителен).

Группировка -- по смысловым блокам, внутри блока по алфавиту английского термина.

## Общие понятия СМО

| EN | RU | Комментарий |
|---|---|---|
| queueing system / queue | система массового обслуживания (СМО) / очередь | «очередь» -- для самого объекта ожидания, «СМО» -- для системы целиком |
| customer / job / request | заявка / запрос | «запрос» более уместно в LLM/GPU-контексте, «заявка» -- классическая ТМО-лексика |
| server / channel | канал (обслуживания) / сервер | «канал» -- классический и предпочтительный термин для формального элемента СМО (Рыжиков 2018: «одноканальная»/«многоканальная система»); «сервер» -- только для прикладного/индустриального смысла (реальная GPU-машина: «сервер инференса», «GPU-сервер») |
| number of servers/channels (Kendall notation) | $n$ (не $c$) | классическая нотация -- `M/H_2/n`, `M/M/n`, не `M/H_2/c` (см. `docs/books/RBOOQLan18`, повсеместно) |
| arrival process | входящий поток / поток заявок | |
| service time | время обслуживания | |
| waiting time | время ожидания | именно В очереди, не включает обслуживание |
| sojourn time | время пребывания | время ожидания + время обслуживания |
| stationary distribution | стационарное распределение | |
| utilization (ρ) | коэффициент загрузки / загрузка (сервера) | |
| stability / stable system | устойчивость / устойчивая система | ρ<1 |
| truncated CTMC | усечённая цепь Маркова | по длине очереди, `queue_truncation` в коде |
| sub-generator | подгенератор | матрица переходов поглощающей цепи (без строки поглощения) |
| absorbing Markov chain | поглощающая цепь Маркова | |
| PASTA (Poisson Arrivals See Time Averages) | PASTA | аббревиатуру не переводить, при первом упоминании дать расшифровку по-английски в скобках |

## Классическая терминология входящего потока (Рыжиков 2018, гл. 2)

Прочитана глава «Математическая модель теории очередей» -- термины ниже извлечены оттуда (своими
словами, не цитаты) как эталонный пример принятой в русской среде лексики для входящего потока.

| EN / понятие | RU | Комментарий |
|---|---|---|
| Poisson process | простейший поток | классическое русское название пуассоновского потока -- через четыре определяющих свойства (стационарный, ординарный, без последействия); предпочтительно «пуассоновского» в прикладных LLM-статьях, но «простейший» -- если текст ближе к классической ТМО |
| renewal process | рекуррентный поток | интервалы между заявками н.о.р. с общей ФР $A(t)$ |
| aftereffect (dependence on prior history) | последействие | «без последействия» -- будущее не зависит от прошлого; «ограниченное последействие» -- зависит только от момента последней заявки (ренуэл-тип) |
| ordinary (simple) point process | ординарный поток | не более одного события за бесконечно малый интервал -- т.е. без одновременных/групповых приходов |
| non-ordinary (batch) process | неординарный поток | возможны пачки/группы одновременных событий -- естественная постановка для batch-arrival моделей |
| flow intensity vs. flow parameter | интенсивность потока $\gamma(t)$ vs. параметр потока $\pi(t)$ | разные величины при неординарном потоке: интенсивность -- средняя скорость прихода заявок (с учётом размера пачки), параметр -- скорость прихода событий (пачек); совпадают только для ординарного потока -- важное разграничение при работе с batch-arrival |
| finite-source (closed) model | примитивный поток / замкнутая СМО | конечное число $R$ источников, интенсивность входа зависит от состояния: $\lambda(R-k)$ при $k$ заявках в системе |
| thinning (of a flow) | просеивание / прореживание потока | случайное (вероятностное) или регулярное (циклическое, напр. round-robin между каналами) |
| superposition of flows | суммирование потоков | сумма независимых простейших потоков -- тоже простейший, с суммарной интенсивностью |
| non-Markov coefficient (normalized higher cumulant) | коэффициент немарковости $\xi_i$ | мера отклонения распределения от показательного по $i$-му моменту; обобщение идеи CV на высшие моменты |
| complementary CDF (survival function) | ДФР (дополнительная функция распределения) | устойчивая аббревиатура в классической лит-ре, $\bar A(t)=1-A(t)$ |
| Laplace-Stieltjes transform | ПЛС (преобразование Лапласа--Стилтьеса) | устойчивая аббревиатура |
| ordered / unordered channels, full/limited accessibility | упорядоченные/неупорядоченные, полнодоступные/неполнодоступные каналы | дисциплина выбора свободного канала при нескольких одновременно доступных |
