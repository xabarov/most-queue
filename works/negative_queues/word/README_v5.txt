Версия v5: абзацные отступы после формул

negative_queues_editable_v5.docx — редактируемая версия Word.
negative_queues_editable_v5.pdf — просмотр; 11 страниц в текущем рендере.

В 23 проверенных местах убран отступ первой строки, поскольку текст после
формулы продолжает рассуждение, поясняет обозначения или условия применения.
Самостоятельные абзацы сохраняют красную строку 1,25 см. Правило применяется
по смыслу, а не ко всему тексту после любой формулы.

Содержимое и оформление всех остальных элементов совпадают с v4.
Сохранены 261 объект формул Word, таблицы, иллюстрации и ссылки.
Исходные DOCX/PDF v4 остаются без изменений.

Воспроизведение: uv run --no-project --with lxml python revise_word_v5.py
Проверки: verification_v5/indent-checks.json и render-checks.json.
PDF проверен визуально на всех 11 страницах. Как и в v4, для локального
PDF-просмотра использована временная копия с Liberation Serif: установленный
Times New Roman некорректно отображает курсивную кириллицу. В самом DOCX
сохранён Times New Roman.
