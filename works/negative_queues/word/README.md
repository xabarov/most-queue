используют стили Word. Название журнала и его шаблон пока не заданы; это рабочая

## Что изменено при переносе

Длинные формулы и группы матриц размещены отдельными строками. У двух выражений
явно обозначены математические группы для одинаковой интерпретации в Word
и LibreOffice; смысл формул сохранён. Звёздочки ПЛС оставлены редактируемыми
литеральными символами в формулах, чтобы исключить их ошибочное прочтение
как знака незавершённой операции. Схемы переходов увеличены для чтения подписей.

Исправлены устаревшие ссылки: временные характеристики и условия существования
моментов находятся в разделе 5, численные результаты — в разделе 6. Исходный
LaTeX, исходный PDF, данные, библиография и изображения сохранены. Научное
содержание статьи не перерабатывалось.

## Проверка и воспроизведение

Сверены все 120 числовых ячеек таблиц, математические выражения, размеры матриц,
источники, рисунки и перекрёстные ссылки. Текст сборки исходного LaTeX совпал
с текстом PDF v3. DOCX прошёл проверку схем OOXML. Просмотрены все 18 страниц
рендера, в том числе места с матрицами, производными, ПЛС и составными рисунками.
Подробности: [content-checks.json](verification/content-checks.json).

PDF получен из временной копии DOCX в LibreOffice. Для предпросмотра использован
метрически совместимый Liberation Serif: установленный локально курсив
Times New Roman неверно отображает кириллицу. В рабочем DOCX сохранён
Times New Roman. Пагинация в Microsoft Word может немного отличаться.

Скрипт `build_word.py` читает LaTeX и связанные материалы из родительского
каталога. Повторная сборка из этого каталога:

```bash
uv run --no-project --with pypandoc_binary --with python-docx --with lxml python build_word.py
```

Сборка заново создаёт DOCX из LaTeX; после начала ручной редакторской работы
сохраните изменения коллеги в отдельном файле перед повторной сборкой.
