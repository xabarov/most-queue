Совместная модель повторов с сохранённой длительностью

1. Исходный процесс

Состояние: число ожидающих Q и пары (B_l, a_l) для всех занятых каналов.
B_l — первоначально выбранная длительность заявки, a_l — уже выполненная
часть работы. Между событиями da_l/dt=1. При a_l=B_l заявка завершается;
при наличии очереди начинает обслуживаться следующая, с новым независимым B.
При общем прерывании одновременно a_l:=0 для всех занятых каналов, а B_l
сохраняются. При RCS сбрасывается только a_l равновероятно выбранного
занятого канала. Заявки из очереди не удаляются и не обгоняют друг друга.

Это марковский процесс с детерминированным движением между скачками и
непрерывными координатами. Внутри области 0<a_l<B_l его генератор:
  L f = sum_l d f / d a_l + lambda (A f - f) + delta (R f - f).
A — положительный приход, R — соответствующий механизм прерывания.
Условия на границах a_l=B_l описывают завершение и замену заявки из очереди.
Зависимость каналов сохраняется общим переходом R, а не поправкой к моментам.

2. Конечная положительная фазовая аппроксимация

Закон B заменяется положительной квадратурой с J узлами d_h и весами omega_h.
Для CV=0.8 это квадратура исходного гамма-распределения. Для CV=1.2 это
квадратура фактической смеси H2; она не подменяется гамма-распределением.
Класс h выбирается один раз при начале обслуживания и сохраняется при повторах.

Детерминированное выполнение работы d_h приближается K последовательными
экспоненциальными фазами интенсивности K/d_h. При прерывании фаза возвращается
в начало ТОГО ЖЕ класса. При общем прерывании это происходит одновременно
на всех занятых каналах. Независимый выбор классов при каждом повторе здесь
был бы другой моделью.

При конечном K время одного прохождения имеет дисперсию d_h^2/K. Его
случайные фазовые интервалы не фиксируются навсегда: это именно приближение
детерминированного выполнения условно по B=d_h. При K -> infinity оно
сходится к d_h. Поэтому одной сетки K недостаточно для вывода о точности.

Состояние конечной цепи хранит длину очереди и неупорядоченный набор
пар «класс, фаза». При n занятых каналах число фазовых состояний равно
binomial(J*K+n-1,n). Перестановки одинаковых каналов объединены без
предположения их независимости. Все переходы и веса вещественны и
неотрицательны. Составные блоки хранятся разреженно.

3. Уравнения и характеристики

Стационарные вероятности конечной цепи находятся из уравнений баланса.
Варианты решения: итерации вложенной цепи и матрично-свободный метод
Крылова. Вероятности вложенной цепи делятся на интенсивности выхода и
нормируются для восстановления стационарного распределения по времени.
События прерывания, не меняющие фазовое состояние, не включаются в
интенсивность выхода; это корректно для экспоненциальных фаз.

Моменты ожидания получаются из факториальных моментов длины очереди:
  E[W] = E[Q]/lambda,
  E[W^2] = E[Q(Q-1)]/lambda^2.
Используются пуассоновский вход, FIFO начала обслуживания и независимость
ожидания помеченной заявки от положительных приходов после неё. Пока она
ожидает, заняты все n каналов; будущие приходы не меняют прерывания и
обслуживание стоящих впереди заявок.

Для ОБЩИХ прерываний W независимо от собственного будущего времени
завершения T после начала обслуживания: требование B независимо от ожидания,
а будущие приращения пуассоновского потока независимы от прошлого в момент
начала обслуживания. Поэтому:
  E[V] = E[W] + E[T],
  E[V^2] = E[W^2] + 2 E[W] E[T] + E[T^2].
Моменты T для исходного непрерывного B доступны непосредственно через M_B:
  E[T] = (M_B(delta)-1)/delta,
  E[T^2] = 2 (M_B(2 delta)-M_B(delta)-delta M'_B(delta))/delta^2.
На верхнем уровне конечной цепи приход блокируется; эффективная интенсивность
принятых заявок равна lambda*(1-p_last). При проверке закона Литтла для
принятых заявок необходима эта поправка. Факториальные формулы с внешней
lambda используются как приближение неограниченной системы; ошибка усечения
контролируется увеличением N.
Для проверки конечной цепи используется соответствующий закон T при
фиксированном классе и конечном K. Это позволяет проверять закон Литтла
отдельно от квадратуры и предельного перехода K -> infinity.

Ядро поддерживает также переходы RCS и вычисляет W, W^2 и E[V] по закону
Литтла. Формула независимой свёртки для V^2 при RCS НЕ используется:
индивидуальная интенсивность зависит от текущего числа занятых каналов.
Основное численное уточнение относится к общим прерываниям — именно там
наблюдалось большое расхождение. Табличный RCS с сохранённой длительностью
по-прежнему помечается как отдельное приближение эффективного обслуживания.

4. Контроль приближения

Изменяются раздельно J (квадратура исходного B), K (ход выполнения работы),
число уровней N и точность решения баланса. Дополнительно сопоставляются
экстраполяции начальных моментов по 1/K с различными тройками значений K.
Коэффициенты экстраполяции определяются только сеткой, без имитационных
значений и без подбора интенсивности прерываний.

Разность уточнений — численная диагностика, а не доказанная верхняя граница
ошибки стационарных моментов. Сходимость процесса на конечном интервале
сама по себе не доказывает равномерную сходимость стационарных моментов.
Для исследуемых параметров дополнительно проверяются известные моменты
одной заявки, устойчивость и независимые прогоны исходной системы.
